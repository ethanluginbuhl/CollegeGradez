# Security Policy

## Supported versions

Security fixes are currently provided for the latest beta release on the
`main` branch. Older releases may not receive fixes.

## Reporting a vulnerability

Please do not report security vulnerabilities in a public GitHub issue. Use
GitHub's private vulnerability reporting feature for this repository, or
contact the maintainer privately through the contact information on the
maintainer's GitHub profile.

Include:

- The affected version or commit.
- Steps to reproduce the issue.
- The potential impact.
- Any suggested mitigation.

Do not include real grade data, exported backups, credentials, or other
personal information in a report. Please allow reasonable time for
investigation and a fix before publicly disclosing the issue.

## Data privacy

CollegeGradez stores grade data locally and exported files can contain
personally sensitive academic information. Treat those files as confidential
and remove them from bug reports unless they contain only fabricated data.
